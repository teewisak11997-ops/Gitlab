1. Smart Energy Monitor (ระบบตรวจวัดและบันทึกพลังงานไฟฟ้าอัจฉริยะ)

คำอธิบาย: ระบบตรวจวัดการใช้กระแสไฟฟ้าและแรงดันในบ้านเรือนแบบเรียลไทม์ โดยส่งข้อมูลผ่านไมโครคอนโทรลเลอร์ขึ้นคลาวด์แดชบอร์ดเพื่อให้ผู้ใช้ติดตามผ่านสมาร์ตโฟนได้

วัตถุประสงค์: เพื่อตรวจวัดและบันทึกการใช้พลังงานไฟฟ้า วิเคราะห์พฤติกรรมการใช้ไฟ และแจ้งเตือนเมื่อเกิดกระแสไฟเกินพิกัด
